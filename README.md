## Highlight: C++ Marketplace

The integrative project for TC1030 and the piece I'd point to first. It models a product catalog where physical goods, digital licenses, and subscriptions each price themselves differently, but are all handled through a single `Producto*` interface.

Covers: abstract classes and pure virtual methods, inheritance hierarchies, runtime polymorphism, operator overloading (`+`, `==`, `<<`), and exception handling for invalid state.
